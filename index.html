Practical questions

Can you modernise an existing substation?

Modernisation is one of the proposed scopes. An assessment defines what can be retained, replaced and integrated.

What information is needed to prepare a proposal?

Start with the facility, the task and a technical contact. Next, we review the single-line diagram, voltage levels, installed equipment and site conditions.

How are installation and commissioning organised?

The proposal defines supplier and local partner responsibilities, qualifications, testing and acceptance milestones.

Can Libyan engineers receive training?

Training can be included in the project scope, with content, location and delivery format agreed before work begins.

How is project financing assessed?

Banks review the buyer, project, security and payment route before financing terms are agreed.
